# Timo's Birthday Puzzle
This project is a small interactive website created as a birthday surprise for Timo.
The goal of the site is to guide the user through a riddle that ultimately reveals the birthday destination.

## Explaination
The puzzle is based on a list of songs, each hiding a single highlighted letter:
1.   Love For **S**ale
2.   Ap**p**lause
3.   Ang**e**l Down
4.   Garden of **E**den
5.   Ali**c**e
6.   Electric C**h**apel
7.   Te**l**ephone
8.   Te**e**th
9.   Schei**s**se
10.  Blade of Gra**s**s

Collecting the highlighted letters forms the word:
> **Speechless**

Entering this result triggers a fun animation revealing the birthday surprise:
> **A trip to the Moulin Rouge in Paris!**
